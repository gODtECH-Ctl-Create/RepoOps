CONTRIBUTOR JOURNEY

GitHub stays the source of truth.

The hub helps you discover work. The contribution itself remains visible and auditable in the repository.

01

Choose

Use the live finder to identify a scoped issue that matches your experience and interest.

02

Claim

Open the issue on GitHub and comment /claim. RepoOps handles the assignment lifecycle.

03

Build

Follow the acceptance criteria, keep scope focused, and run npm run check.

04

PR

Open a focused pull request linked to the issue and include the validation evidence maintainers need.

05

Review

Respond to CI and maintainer feedback. RepoOps will increasingly surface who needs to act next.

06

Merge

Completed work stays connected to its issue and becomes part of RepoOps’ operational history.
