# Code of Conduct

RepoOps is intended to be a professional, collaborative open-source project.

## Expected behavior

Participants should:
- communicate respectfully and constructively
- review code and ideas rather than attacking people
- assume good intent while still questioning unsafe technical decisions
- give contributors clear, actionable feedback
- respect maintainer decisions about project scope and security
- avoid harassment, discrimination, intimidation, or personal attacks
- avoid spam, low-effort mass contributions, and deliberately disruptive behavior

## Technical disagreement

Strong disagreement is normal in engineering. Keep discussions focused on evidence, trade-offs, maintainability, security, and user impact.

Maintainers may close or redirect work that is out of scope, duplicated, unsafe, or insufficiently tested. This is not a judgment on the contributor.

## Enforcement

Maintainers may edit or remove comments, close issues or pull requests, restrict participation, or block users when necessary to protect contributors and the project.

Serious conduct concerns should be reported privately to the repository owner rather than debated publicly in an issue thread.
